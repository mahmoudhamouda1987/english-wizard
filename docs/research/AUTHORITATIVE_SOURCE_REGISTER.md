# English Wizard — Authoritative Educational Source Register

**Audit date:** 2026-08-20

## 1. CEFR / Council of Europe

Primary source: Council of Europe, *Common European Framework of Reference for Languages: Learning, Teaching, Assessment — Companion Volume* (2020).

Official source:
https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-companion-volume-and-its-language-versions

Use in English Wizard:
- CEFR level descriptors and progression.
- Mediation.
- Online interaction.
- Spoken-language qualitative features and phonology.
- Action-oriented curriculum and assessment alignment.

Important constraint: CEFR is a descriptive framework. English Wizard may produce internal learning estimates but must not imply that those estimates are official CEFR certification.

The Council of Europe states that the Companion Volume replaces the earlier 2001 descriptor set for pedagogical use and adds/extends areas including mediation, online interaction and phonology.

## 2. IELTS

Primary source ecosystem: IELTS official assessment resources and band descriptors.

Official source:
https://ielts.org/organisations/ielts-for-organisations/understanding-ielts-scoring/resources-for-setting-your-ielts-scores

Writing band descriptors:
https://ielts.org/cdn/Guides/ielts-writing-band-descriptors.pdf

Use in English Wizard:
- Exam task familiarisation.
- Timing and response structure.
- Rubric-aware preparation.
- Internal readiness estimates.

Constraint: preparation and readiness estimates must remain distinct from official IELTS scoring/certification.

## 3. Cambridge English

Primary source ecosystem: Cambridge English qualification and assessment resources.

Official source:
https://www.cambridgeenglish.org/educators-organisations/accept-verify-exams/higher-education-institutions/exams-tests/

Use in English Wizard:
- Qualification-specific objectives.
- CEFR-aligned readiness mapping.
- Assessment-language and rubric design references.

Constraint: English Wizard is a preparation platform, not a Cambridge certification provider.

## 4. Licensing / provenance rule

Every reusable content item must record:
- source;
- source type;
- rights/licensing state;
- whether reuse is permitted;
- target level;
- learning objective;
- review state;
- version;
- safety/answer/ambiguity/difficulty validation state.

External text/audio must not be copied into production merely because it is publicly viewable.

## 5. Research-to-curriculum chain

Authoritative descriptor → capability → sub-capability → skill → language resource → activity → assessment evidence → mastery criterion → mission → retention/review policy.

## 6. Verification status

This register establishes the authoritative reference map. It does **not** by itself verify every curriculum item. Item-level traceability and reviewer approval remain part of the remaining contract work.
